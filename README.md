# Sākṣī Documentation

Official documentation for the Sākṣī Android ecosystem.

Sākṣī is an open-source Android media-preservation ecosystem designed to keep an independent local copy of important photos and videos. It consists of four components: Camera, Vault, Portal, and the Sākṣī SDK.

The documentation covers the ecosystem's architecture, installation, everyday usage, development, and SDK integration.

## Source Code

Explore the source code of each component:

- [Sākṣī Camera](https://github.com/RajnishKMehta/Sakshi-Camera): Android camera application for capturing photos and videos.
- [Sākṣī Vault](https://github.com/RajnishKMehta/Sakshi-Vault): Independent background application responsible for storing media.
- [Sākṣī Portal](https://github.com/RajnishKMehta/Sakshi-Portal): Application for browsing, viewing, and managing stored media.
- [Sākṣī SDK](https://github.com/RajnishKMehta/Sakshi-SDK): SDK for communication and integration with Vault.
