## My Projects

These are my some of open source projects

### [Sākṣī](https://github.com/RajnishKMehta/Sakshi-Docs)

Sākṣī is an Android media-preservation ecosystem designed to help you keep a separate, hidden copy of your important media and private files away from your regular phone storage. It consists of three applications and an SDK:

*   **[Camera](https://github.com/RajnishKMehta/Sakshi-Camera)**: Captures photos and videos and can synchronize media with Vault.
*   **[Vault](https://github.com/RajnishKMehta/Sakshi-Vault)**: A background-only storage application responsible for managing preserved media.
*   **[Portal](https://github.com/RajnishKMehta/Sakshi-Portal)**: A user-facing application for browsing, viewing, exporting, and managing stored media.
*   **[SDK](https://github.com/RajnishKMehta/Sakshi-SDK)**: Provides the communication interface between compatible client applications and Vault.

### [DhwaniControl](https://github.com/RajnishKMehta/DhwaniControl)

An Android utility designed to restore access to the native volume panel on devices with broken or unresponsive physical volume buttons. It provides Quick Settings access, a floating button, edge-swipe gestures, and Assist App integration.

### [gh-perma](https://github.com/RajnishKMehta/gh-perma)

An ID-based GitHub URL resolver. Since GitHub usernames can change, this tool uses immutable GitHub user IDs to create stable profile and repository links. It resolves the current username through the GitHub API, helping links remain valid even if a username changes.

### [EverLink](https://github.com/RajnishKMehta/EverLink)

A lightweight, self-hostable URL shortener and redirector designed for Cloudflare Pages. It supports configurable destinations and convenient Discord invite code handling.
